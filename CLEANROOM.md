# How Mochi Studio was written

Mochi Studio was written without Live2D Inc.'s software, and without other
apps' code, artwork or text.

- Its code was written by AI coding agents directed by the maintainer. They
  worked only from the project's own written briefs, Mochi2D's public API and
  documentation, model data files, general programming knowledge and
  permissively licensed libraries.
- They did not view, install or run any Live2D SDK component or manual, or any
  third-party implementation of the format, and they did not use Live2D Inc.'s
  sample models.
- Compatibility with VTube Studio's settings files and plugin API was written
  from descriptions prepared from its public documentation and from settings
  files. No VTube Studio code, artwork or text is included.
- The briefs and reports of this process are kept in a private record.
- Contributions follow the same rule: see CONTRIBUTING.md.
