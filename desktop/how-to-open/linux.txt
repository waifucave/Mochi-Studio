Mochi Studio for Linux: how to open it
======================================

This build is not signed. Linux does not warn about that, but a downloaded
file is not executable until you allow it.

1. Make the AppImage executable:
     chmod +x "Mochi Studio-<version>.AppImage"
   (or: right-click > Properties > Permissions > "Allow executing file as
   program").
2. Run it: double-click it, or ./"Mochi Studio-<version>.AppImage"
3. If it does not start and says FUSE is missing, install libfuse2
   (Ubuntu 22.04 and later: sudo apt install libfuse2t64, or libfuse2 on
   older releases), or run it with --appimage-extract-and-run.

More: docs/desktop.md and docs/user-guide.md in the source repository.
